광고 캠페인용 랜딩페이지의 **컨셉 작업본**입니다. 라이브 배포본이 아닙니다.

## ⚠️ 추적 픽셀이 꺼져 있습니다

이 저장소는 GitHub Pages로 공개될 수 있으므로, 테스트 트래픽이 회사 광고 계정의
전환 데이터를 오염시키지 않도록 모든 추적을 비활성화했습니다.

| 항목 | 작업본 | 라이브 값 |
|---|---|---|
| Meta 픽셀 | `''` (꺼짐) | `1387430733300442` |
| GTM | `''` (꺼짐) | `GTM-53PX7FSF` |
| 당근 픽셀 | `''` (꺼짐) | `1785978728314816001` |
| GA4 | `''` | GTM 내부에서 연결 |
| `<noscript>` 폴백 픽셀 | 제거됨 | GTM iframe + Meta img |

로더는 전부 ID 값으로 게이트되어 있어(`if(!w.KARROT_ID) return;`, `!!window.META_PIXEL_ID`)
ID를 비우면 스크립트 자체가 로드되지 않습니다. 실제 브라우저(390x844)로 확인한 결과
추적 도메인 요청 0건, `fbq`/`karrotPixel` 모두 `undefined`입니다.

**라이브에 반영할 때는 위 표의 값을 되돌리고 `<noscript>` 블록을 복원해야 합니다.**

시세 API(`PRICE_API`)는 페이지 렌더에 필요하므로 그대로 두었습니다.

## 알려진 작업 항목

- 엔진이 구버전입니다. 본 랜딩의 스크롤 개선(모바일 속도 상한 3.0화면/s, 재방문자
  상한 해제, iOS 상단 바 탭)이 반영되어 있지 않습니다.
  현재: 하향 상한 1.7, 관성 2.2, 진행 상한 0.012, 죽은 1.9 분기.
- 프리롤 첫 화면이 전부 보이기까지 약 2.1초가 걸립니다
  (스크롤 힌트 `animation-delay: 1.5s` + `0.6s`). 평균 참여 시간 7초 기준으로 과합니다.
- 가격(`ar_price`)이 시세 API 응답 이후에 채워져, 첫 화면에서 가장 중요한 숫자가
  가장 늦게 도착합니다.
- 상단 데모 전환 바(`?c=` 프리셋 스위처)는 실전 배포 시 제거 대상입니다.

## 캠페인 파라미터

- `?c=s25fe` 특정 기종 전략 세일 / `?c=daran` 전체 세일 / `?c=preorder` 사전예약 / `?c=off` 기본
- 파라미터가 없으면 데모 기본값 `s25fe`
